# 插件图标

## 图标文件要求

请将以下尺寸的 PNG 图标放在此目录中：

- **icon16.png** - 16x16 像素（工具栏图标）
- **icon48.png** - 48x48 像素（扩展程序页面图标���
- **icon128.png** - 128x128 像素（Chrome 网上应用店）

## 快速生成图标

你可以使用在线工具生成图标：
1. 访问 https://www.favicon-generator.org/
2. 上传你的设计图片
3. 下载 PNG 格式的图标

## 推荐设计

建议使用包含以下元素的图标设计：
- 地球/翻译的符号（🌐 或 📖）
- 简洁的蓝紫色配色（与弹窗主题一致）
- 清晰可识别的形状

## 临时替代方案

如果你现在没有图标，可以：
1. 使用任何 16x16, 48x48, 128x128 的 PNG 图片
2. 或者在 manifest.json 中注释掉 icons 配置（临时方案）
